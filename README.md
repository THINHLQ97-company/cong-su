# CỘNG SỰ — bản dựng để chơi thử

Trò chơi dạy dùng AI qua nhập vai công việc. Đây là **bản đã dựng sẵn** để mở
bằng trình duyệt; mã nguồn, bảng nội dung và tài liệu thiết kế nằm ở kho riêng.

- `index.html` — vào game
- `kit.html` — trang tra cứu chất liệu (hình nhân vật, cây tiến hoá trợ lý)

Không có tệp ảnh hay âm thanh nào: toàn bộ hình và tiếng được sinh ra bằng mã
lúc chạy.
